Learning path · Google Cloud

Software Engineering on Google Cloud

You build the services everything else runs on, and you make them dependable.

Free, like everything here: no sign-up, no paywall. Only the cloud you practise on may charge; the open-source path costs nothing.

Platform:AWSAzureGoogle CloudOpen sourceCompare all

Data, ML and AI work all stand on ordinary software: APIs, databases, queues, tests, pipelines and monitoring. Strong software engineering is the fastest way to become good at all the other paths.

Every topic below is a concept (the job) with the Google Cloud product that does it. Learn the concept once; on another platform only the product name changes. Read alongside: Agent Harness, drawn simply · Your first 30 days.
