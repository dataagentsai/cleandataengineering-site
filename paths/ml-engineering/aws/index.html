Learning path · AWS

ML Engineering on AWS

You turn models into reliable products: features, training, serving and monitoring.

Free, like everything here: no sign-up, no paywall. Only the cloud you practise on may charge; the open-source path costs nothing.

Platform:AWSAzureGoogle CloudDatabricksOpen sourceCompare all

Classic machine learning still runs most predictions in business: churn, fraud, demand, pricing. ML engineers make those models repeatable, served, monitored and retrained, which is also the foundation for LLM work.

Every topic below is a concept (the job) with the AWS product that does it. Learn the concept once; on another platform only the product name changes. Read alongside: The AI Universe · Certification prep on this site.
