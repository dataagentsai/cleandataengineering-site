Learning path

LLM Engineering

You work on the models themselves: data, tuning, serving and cost per token.

Role:Data EngAI EngLLM EngML EngSoftware EngFDE

Why this path

AI engineers use models; LLM engineers shape them. That means knowing how a model is trained, how to adapt one to a task, how to serve it fast and cheap, and when a small model beats a big one.

How to use this page: 1. learn the key concepts, which are the same everywhere; 2. pick your platform; 3. work through Crawl, Walk and Run.

CrawlBeginner · 6 weeksUnderstand how a language model works by building a tiny one, then use real ones well.WalkIntermediate · 3 monthsAdapt and serve models: fine-tune, host open weights and measure quality and cost.RunAdvanced · 6 months +Build the data and training pipeline for a model, and publish it.
