Learning path · Google Cloud

LLM Engineering on Google Cloud

You work on the models themselves: data, tuning, serving and cost per token.

Free, like everything here: no sign-up, no paywall. Only the cloud you practise on may charge; the open-source path costs nothing.

Platform:AWSAzureGoogle CloudDatabricksOpen sourceCompare all

AI engineers use models; LLM engineers shape them. That means knowing how a model is trained, how to adapt one to a task, how to serve it fast and cheap, and when a small model beats a big one.

Every topic below is a concept (the job) with the Google Cloud product that does it. Learn the concept once; on another platform only the product name changes. Read alongside: The AI Universe · Agent Harness, drawn simply · Certification prep on this site.
