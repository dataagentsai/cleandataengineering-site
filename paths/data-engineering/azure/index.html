Every AI system is only as good as the data under it. Data engineers build that floor: pipelines that land data, tables that hold it, checks that stop bad rows, and models that give each metric one meaning.

Every topic below is a concept (the job) with the Azure product that does it. Learn the concept once; on another platform only the product name changes.
