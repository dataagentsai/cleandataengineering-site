Learning path

AI Engineering

You build products and agents where a model does part of the work, safely.

Role:Data EngAI EngLLM EngML EngSoftware EngFDE

Why this path

Most of an AI system is ordinary software around a small model call: the tools, the checks, the state, the evaluation and the bill. AI engineers build that harness so the product holds up after the demo.

How to use this page: 1. learn the key concepts, which are the same everywhere; 2. pick your platform; 3. work through Crawl, Walk and Run.

CrawlBeginner · 6 weeksCall a model, get checked structured output, and give it a few safe tools.WalkIntermediate · 3 monthsBuild the harness: retrieval, state, approvals, tracing and evaluation on every change.RunAdvanced · 6 months +Prove an agent before it meets real people, and run many of them at a known cost.

Read alongside: The AI Universe · Agent Harness, drawn simply · The Agent Harness Series · Eval Harness, drawn simply · Certification prep on this site.

Step 1 · the same everywhere

Key concepts

Learn these ideas first. They are the same on every cloud and with every tool; only the product names change. Each one is a short page: what it is, why it matters, an example and the common mistake.

Working with models

Deterministic firstIf ordinary code can do it, code does it. The model handles only the part that needs judgement.CrawlTokens and the context windowModels read and write in tokens, and can only see so many at once.CrawlStructured outputAsk the model for JSON in a fixed shape, then check it in code.CrawlHallucination and groundingConfident answers that are not true, and how to anchor answers to sources.CrawlTemperature and samplingHow the model picks the next token from its options.Crawl

Tools and agents

Tool callingThe model asks your code to do something; your code decides whether it runs.CrawlThe agent loopModel, tool, result, model again, until done or a limit is hit.WalkThe harnessEverything around the model that makes it safe to use.WalkState and durable waitsRemember where a long task was, survive crashes, and wait days for a human.RunHuman approvalA person says yes before anything that is costly or cannot be undone.Walk

Knowledge

EmbeddingsTurn text into a list of numbers so similar meanings sit close together.CrawlChunkingHow you cut documents into pieces decides what search can find.WalkRetrieval-augmented generation (RAG)Find the right passages first, then let the model answer from them, with citations.Walk

Safety and proof

Checks before and afterCode that inspects what goes into the model and what comes out, and can stop it.WalkPrompt injectionText in a document or tool result that tries to give the model new orders.WalkEvaluationProve it works on cases you wrote down, every time you change it.WalkTracing an AI systemRecord every model call, tool call, token and cost for each turn.WalkLLM cost: tokens, caching and routingKnow the cost per answer, then cut it.Walk

Engineering basics

Version control and pull requestsEvery change saved, explained and reviewed before it goes live.CrawlAPIs and contractsA promised way for programs to talk, which you change carefully.CrawlIdempotencyRunning the same thing twice gives the same result as running it once.CrawlRetries, timeouts and backoffAssume calls fail sometimes, and handle it calmly.WalkPorts and adaptersCode to an interface, so you can swap a vendor without a rewrite.Run
