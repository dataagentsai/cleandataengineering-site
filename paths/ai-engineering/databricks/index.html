Learning path · Databricks

AI Engineering on Databricks

You build products and agents where a model does part of the work, safely.

Free, like everything here: no sign-up, no paywall. Only the cloud you practise on may charge; the open-source path costs nothing.

Platform:AWSAzureGoogle CloudDatabricksOpen sourceCompare all

Most of an AI system is ordinary software around a small model call: the tools, the checks, the state, the evaluation and the bill. AI engineers build that harness so the product holds up after the demo.

Every topic below is a concept (the job) with the Databricks product that does it. Learn the concept once; on another platform only the product name changes. Read alongside: The AI Universe · Agent Harness, drawn simply · The Agent Harness Series · Eval Harness, drawn simply · Certification prep on this site.
