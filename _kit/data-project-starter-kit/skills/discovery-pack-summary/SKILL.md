# Discovery pack summary

For: BA, Tech Anchor

Compares what people say, what documents say and what the data shows. Use at the end of discovery, before the discovery sign-off.

## You give it
- Interview and meeting notes.
- Documents about the sources and the old reports.
- What was seen in the real data (counts, samples, profiling notes).

## Steps
1. For each topic (each source, each number), set the three views side by side.
2. Mark where they agree.
3. Mark where they disagree. A disagreement is a finding.
4. Mark where one view is missing.
5. List the results of the fail-fast tests: sample, access, meaning, one number, volume and timing, change, user, running.
6. Say what to ask next, and whom.

## You get
`01-discovery/discovery-summary.md`: agreements, disagreements, gaps, test results, next questions.

## Check before you hand it over
- [ ] Each statement says which of the three views it came from.
- [ ] No disagreement was smoothed over.

## Rules for every skill
- Use only what is in the files you were given. Do not invent a fact, a name, a number or a date.
- Where something is missing, write `UNKNOWN` and who could answer.
- After each statement taken from a file, say which file it came from.
- Use the words in `00-project/glossary.md`. If a word is used two ways, say so.
- Write in plain words, for people who do not write code.
- The result is a draft. End with the line: `Draft by an AI assistant. To be checked by: ______`.
- Client data, personal data and secrets stay out of any tool the client has not approved.
