MyClaudeCode

A mini coding agent used as an instrument to put numbers on unmeasured coding-agent advice.

Starting · join earlyAI Engineering

3 of 10 tasks done

1 · Purpose

MyClaudeCode builds a small coding agent to understand how tools like Claude Code work from the inside. Official guidance already explains how to set these tools up, but it does not measure the mechanisms it describes. This project runs experiments to find the numbers: when instruction files get too big, when subagents pay off, what compaction forgets, and where answer quality starts to fall. It is for engineers using coding agents on large codebases who want evidence, not folklore.

For: Engineers and team leads who use coding agents on large codebases.

2 · Business benefits

Lower token spendKnowing which always-loaded layer dominates the baseline lets a team cut it first.
Fewer lost instructionsA catalogue of what compaction forgets tells teams what to back up or restate.
Evidence-based settingsThresholds for when to clear or compact come from measurement instead of guesses.
Reuse before buildingA reuse ledger shows which existing open-source tools already cover each need.

3 · Status and how to join

Starting · join early. Early days: the shape is still being decided, so joiners now have the most say. Lead: Basant Choudhary.

Good first tasks this week:

  • Run the existing usage tools over your own sessions and share the baseline split.
  • Write the trace format for the mini agent's first version.
  • Add one checked entry to the reuse ledger.
Join this project

The code is not public yet; joiners get access.

4 · Requirements

What it must do

  • Provide a small coding agent with a trace from the first version.
  • Split the always-loaded context baseline by layer.
  • Force compaction on demand and record what kind of information it removes.
  • Measure the break-even point where a subagent saves more than it costs.
  • Measure how many skills can be loaded before selection breaks.
  • Package a context-governance kit: status line, warning hook and pre-compaction backup.

How well it must do it

  • Every published claim is backed by a number or a reproduced failure; unproven claims are cut.
  • Measure context mechanics, which do not depend on the model; label anything model-dependent.
  • Every experiment runs from a fresh clone by a stranger.
  • Free open-weight models by default.
