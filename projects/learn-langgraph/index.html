LearnLangGraph

A hands-on LangGraph course in three waves: graphs without an LLM, then agents, then production patterns.

Active · join meAI Engineering

5 of 10 tasks done

1 · Purpose

LearnLangGraph teaches the LangGraph library by doing, one small runnable lesson at a time. Wave 1 uses no language model at all, so state, nodes, routing and loops are learned on plain code. Wave 2 adds a free open-weight model, and the agent loop becomes just one more node. It is for engineers who want to build agents on a clear mental model rather than copy examples.

For: Python developers and data engineers starting with agent workflows.

2 · Business benefits

Faster onboardingA new engineer can go from zero to a tool-using agent with memory in a few evenings.
Fewer fragile agentsLearning routing and loops on deterministic code first makes later agent bugs easier to find.
Zero model spend while learningLessons run on a free model tier, and tests use a scripted fake model with no network.
A reusable teaching assetEvery lesson is a runnable file plus a test, so a team can use it as its own internal course.

4 · Requirements

What it must do

  • Teach state, nodes, edges, conditional routing, reducers, parallel branches, loops and streaming with no LLM.
  • Finish Wave 1 with a capstone graph that triages Spark job anti-patterns.
  • Teach an LLM as a node, raw tool calling, a hand-built ReAct loop, the prebuilt agent, memory and structured-output routing.
  • Finish Wave 2 with a capstone cost assistant that combines a guard, an agent, tools and memory.
  • Plan Wave 3: human approval, time travel, subgraphs, map-reduce, supervisor multi-agent, durable storage and evals.
  • Publish the whole course as one generated HTML page with diagrams, code, real output and exercises.

How well it must do it

  • Every lesson has a table-driven test.
  • Tests need no API key; a scripted fake model replaces the real one.
  • Switching model provider is two settings, not a code change.
  • Real model output is cached so the page can be rebuilt without calling the model.

Also: Lesson files → Model adapter: ask the model · Tests → Scripted fake model: replay answers · Tests → Lesson files: check behaviour · Page builder → Lesson files: read code and output

9 · What you'll learn

  • A graph is a function: state goes in, state comes out.
  • Reducers decide how two updates to the same key are merged.
  • An agent is a graph with a loop where one node calls a model.
  • Checkpointers give memory, pause and resume.
  • How to test agent code without calling a model.

Level-up questions

  • When does a graph framework help, and when is a plain loop clearer?
  • How do you stop an agent loop safely?
  • Where should a human approval step go in a real workflow?
