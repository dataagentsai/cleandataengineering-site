Which model should our agent use? Wrong question. An agent turn has four or five steps, and each one has a different best answer, sometimes "no model at all". Here is how we choose, with a scorecard you can fill in this week.

Picking one "best" model for a whole agent is the wrong question. Test candidates on a small golden set of your own tasks, weigh accuracy, cost, speed and reliability for each step, decide where your data is allowed to go, and give each step the cheapest worker that passes, which is often plain code. Then pin the versions and test again whenever a model changes.
