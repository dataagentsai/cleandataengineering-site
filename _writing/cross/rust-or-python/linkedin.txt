Someone on your team wants to rewrite the agent in Rust "for speed". The model call takes three seconds; the Python around it takes thirty milliseconds. Here is where Rust really earns its place in an agent, where Python does, and the three questions that decide each part.

Python wins for the thinking parts of an agent: orchestration, prompts, evals and fast iteration, with the whole AI library ecosystem behind it. Rust wins for the heavy lifting: sandboxes, gateways on the hot path, and tools shipped as one small binary. The model call usually dominates latency, so Rust helps only where the model is not involved.
