Your agent will change model, cloud and trace tool more than once this year. If each change means hunting vendor calls through the loop, the agent breaks every time. Six patterns from ordinary software engineering fix that, and none of them is new. Five drawings, one real agent.

Everything around an agent changes every few months: the model, the gateway, the trace backend, the cloud. A handful of old software design patterns keep those changes small. Put each vendor behind a port, pick the adapter in one YAML file, line up the checks so any one can stop a call, wrap calls in retries and traces, and make every adapter pass the same contract tests.
