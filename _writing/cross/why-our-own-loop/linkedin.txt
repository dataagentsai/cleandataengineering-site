Everyone told us to pick an agent framework. We wrote the loop ourselves instead: 416 lines, four of which actually go round. Here is what a framework would have given us, what it would have cost, and the exact conditions under which we would switch.

Our reference agent, a support agent that can move real money, runs on a loop we wrote ourselves in one file of 416 lines. We did it so every budget and check sits at a place a test can reach. We kept the door open by putting the loop behind a port: a Pydantic AI version is written, LangGraph and Claude Agent SDK versions are planned, and all of them must pass the same frozen tests.
