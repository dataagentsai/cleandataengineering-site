A network timeout sends the same orders file twice. Your pipeline loads it twice, and the revenue tile quietly doubles from ₹1,250 to ₹2,500. Nothing failed, so nothing alerted. Here is why every pipeline sees repeats, and six simple patterns that make a second run harmless.

Every pipeline sees the same data more than once: retries, queues that deliver twice, files sent again, backfills and tired re-runs. A pipeline is idempotent when processing the same input twice gives the same result as processing it once. This post shows, with numbers from real recorded runs, how a naive pipeline doubles revenue and the six patterns that make repeats safe.
