"Give the agent memory" sounds like one feature. It is really three different things, and mixing them up is how agents end up quoting yesterday's claim status or repeating a lie a user taught them. Here is agent memory with the magic taken out.

An agent's memory is not a mysterious brain. It is three plain things: this conversation saved in a checkpoint, a few facts about a person kept across visits, and documents it looks up. This post shows what to store, what to forget, where it lives, and why anything that changes should be read again from the real system instead of remembered.
