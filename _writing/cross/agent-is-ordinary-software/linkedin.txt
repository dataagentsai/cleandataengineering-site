People say the model is 10% of an agent. It is a nice slogan. So we measured it. In our open reference agent, the code that calls the model is 3% of the lines. Tests alone are 18,415 lines. Here is the count, the method, and how to check your own.

We counted every line of code in our reference agent and sorted it by job. The code that calls the model is 817 of 24,631 lines, about 3%, and the rest is tests, checks, durable workflows, state, tracing and plumbing. So most of building an agent is ordinary engineering, and the skills you already have apply.
