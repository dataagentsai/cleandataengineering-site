Teams spend weeks choosing an agent framework. But the loop it gives you is the smallest part of a working agent. Here is a fair look at LangGraph, the OpenAI Agents SDK, the Claude Agent SDK and plain code, a "pick this when" table, and the one design choice that makes the decision cheap to undo.

Every agent runs the same small loop: build the context, ask the model, run the tools it asked for, and go round again. LangGraph, the OpenAI Agents SDK, the Claude Agent SDK and a plain while-loop are four ways to own that loop, each with real gifts and real costs. Pick by the job, then put the loop behind a port so you can change your mind.
