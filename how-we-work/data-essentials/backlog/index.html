Topic 13 · The reusable backlog

The corpus backlog for a data project

285 backlog items for a data project, organised by phase and by hop: Discovery (the full list), then Source to Land, Land to Bronze, Bronze to Silver, Silver to Gold, Gold to Semantic and Semantic to Consumption. Each item says whether it is common work done once, or repeats per source, per dataset or per data product, where the unit of delivery is a group of KPIs and the dashboard for them.

The idea

One KPI group and its dashboard, traced through every layer

Take a group of KPIs and the dashboard that shows them. To deliver it, work happens in every layer. Some of that work is common: environments, access model, standards, metadata store. You do it once. Some is per source or per dataset: profile it, agree its keys, load it, clean it. Some is per data product: define the KPIs, build the facts, reconcile, accept the dashboard. The matrix counts the items in each cell.

How to use it

Start with all, remove what does not apply

Items owned by BA: 109, Tech Anchor: 170, PM: 59. Types: Document (write it down), Decision (someone decides), Spike (learn something risky, timeboxed), Slice (a thin working piece), Run (a repeated activity). Phase follows the lifecycle stage: Discover (stages 1 to 3), Design (4), Build (5 to 6), Test (7), Run and close (8 to 10).

Do not skip Discovery. It is cheap, and it prevents the causes that are most expensive later.

FAQ

Questions people ask

What is a data product here?

A group of KPIs and the dashboard that shows them, with the datasets they need. It is the unit you deliver and accept. One project may deliver several.

How do I use the matrix?

Read down the columns. The first two columns are done once. The last three repeat. To plan, enter how many sources, datasets and data products you have, and read off the number of items to plan.

Is this a Jira backlog?

No. It is a reusable starting list at scope level, between an epic and a task. Download the CSV, keep what applies, and split items into tasks in your own tool.
