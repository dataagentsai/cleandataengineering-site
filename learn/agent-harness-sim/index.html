Send a message. Watch the harness work.

You are Rohan, a policyholder of a motor insurer. You have signed in and the claims assistant is open. Type a message, or pick one below, and press Send. The map lights up step by step: every system the message touches, every check that fires, the code that runs, the Python objects it holds, and the JSON that goes to the model and comes back. When the reply arrives, scroll down to see what reached App Insights and Prometheus, and what the evaluations said.

No real agent runs here. The page has a small copy of the agent's routing rules, and it replays what the real claims assistant did on Azure. Steps marked real use replies, timings and payloads recorded from runs on 13 and 14 October 2026. Steps marked illustrative show what the code does, but the values were not recorded from a run.

  • Plain words: what happened, and why it matters.
  • Code: the real file and function that does it.
  • Variables: the Python objects at that moment.
  • Sent and Received: the JSON or HTTP on the wire.
