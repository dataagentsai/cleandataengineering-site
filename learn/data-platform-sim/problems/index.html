The Problem Lab: break it, try the naive fix, fix it right

The problems that cost real teams their nights. Each one is told in three steps: what you see (the checks go red), the naive fix (applied for real, and it fails or makes things worse), and the right fix (the checks go green). Every table, check, error and commit comes from a real Spark and Delta Lake run.

real Recorded on local[2] Spark 3.5.1 + Delta Lake 3.2.0 on 2026-10-28. The naive fixes were run too, so their failures are real, not described.
