Agent Harness Tutorial · Architecture

What Azure gives, what we build, what each agent does

For each concern, how much does Azure give us, how much do we code once for every agent, and how much does each agent team still write? Azure gives us the plumbing. The parts that make an agent trustworthy stay in our code.

What stays ours, in eight tiles: the control loop, context assembly, policy positions, tool design, the replay recorder, the span contract, undo and idempotency, and cost per outcome.

For every concern's choice in detail, with the Azure and open-source options next to it, see Tech stack.

Want every detail? The long version is in the Series: what Azure gives, what we build once.
