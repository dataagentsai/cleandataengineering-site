Alert rules

An alert is a saved question that runs on a schedule and tells a person when the answer is "yes". On Azure today there are six, written in KQL against the Log Analytics workspace. The reference agent has a fuller set written for Prometheus. Both lists below are read from the real files.

On Azure: 6 scheduled log alerts (infra/modules/alerts.bicep)

Each runs every 15 minutes and emails the owner through the action group ag-fnol-owner. Plus the $10 monthly budget emails at 50%, 80% and a 100% forecast.

AlertSeverityWhat it means and what to doThe KQL
Claims agent: a turn failed
turn-failed		Sev 1A policyholder got "I am having trouble answering right now". Open the trace by its SessionId in App Insights > Transaction search.
AppDependencies
| where Name == "agent.turn" and tostring(Properties["agent.turn.result"]) == "failed"
| project TimeGenerated, conversation = SessionId, run = tostring(Properties["agent.run.id"])
Claims agent: a container crashed or failed to start
agent-not-starting		Sev 1A container exited with code 1 or printed a Python traceback. Container Apps > Revisions and replicas, and the console log.
union
  (ContainerAppSystemLogs_CL | where Reason_s == "ContainerTerminated" and Log_s has "exit code '1'"
   | project TimeGenerated, app = ContainerAppName_s, revision = RevisionName_s, what = Log_s),
  (ContainerAppConsoleLogs_CL | where Log_s startswith "Traceback" or Log_s has "Error:"
   | project TimeGenerated, app = ContainerAppName_s, revision = RevisionName_s, what = Log_s)
Claims agent: model calls failing
model-calls-failing		Sev 2APIM answered a chat-completions call with an error, or the agent's model call failed. A 403 can be a Content Safety block; a 429 the rate limit; a 5xx Groq.
union
  (AppRequests | where Name has "chat/completions" and not(ResultCode startswith "2")
   | project TimeGenerated, what = strcat("APIM returned ", ResultCode)),
  (AppDependencies | where Name == "gen_ai.chat" and Success == false
   | project TimeGenerated, what = "the agent's model call failed")
Claims agent: Content Safety blocked a call, or is unavailable
content-safety		Sev 2block:<category> means a prompt or completion was refused at the gateway; unavailable means it was not screened (F0 quota spent, or the service down).
AppDependencies
| where Name == "gen_ai.chat"
| extend verdict = tostring(Properties["agent.gateway.x-content-safety"])
| where verdict has "block" or verdict has "unavailable"
| project TimeGenerated, verdict
Claims agent: a policyholder is waiting for a person
person-needed		Sev 3A conversation was handed to a person, or a payout above the automatic limit is waiting. Open /ops/desk.
union
  (AppDependencies | where Name == "agent.escalation.raise"
   | project TimeGenerated, what = strcat("hand-off ", tostring(Properties["agent.escalation.id"]), " (", tostring(Properties["agent.escalation.rule_id"]), ")")),
  (AppDependencies | where Name == "agent.turn" and tostring(Properties["agent.turn.result"]) == "needs_approval"
   | project TimeGenerated, what = strcat("payout waiting, conversation ", SessionId))
Claims agent: an inline check blocked a reply or a call
check-blocked		Sev 3A rule refused something: injection phrasing, personal data, a promise of cover, foreign currency, a write the policyholder did not ask for. Read it: an attack, or a rule misfiring.
AppDependencies
| where Name == "agent.policy" and isnotempty(tostring(Properties["agent.policy.blocked_by"]))
| project TimeGenerated, rule = tostring(Properties["agent.policy.blocked_by"]), position = tostring(Properties["agent.policy.position"])
