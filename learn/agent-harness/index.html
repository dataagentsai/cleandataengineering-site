Agent Harness Tutorial · Start

Agent Harness, drawn simply

This is the short, picture-first version of the Agent Harness Series. The Series is the full deep dive; these pages are the map. Every page has one drawing, a few plain sentences, and doors to the next level down.

Goes inA question from a customer
What happensWe follow it through every box of the harness, one page per box
Comes outYou can point at any box and say what it does, why it is there, and what it is built with

How the pages are arranged.

  1. Architecture: the horse and the harness, the harness as one block, the abstract big picture, and the same picture on Azure. No code yet.
  2. End to end: one drawing of a single message going all the way through. Every box on it is clickable.
  3. The deep dives: the core loop, context, checks, state and memory, DBOS, and eval. Each one zooms in two or three levels.
  4. Real flows: real messages sent to the assistant on Azure, each traced box by box.
  5. Tech stack: for every concern, what we chose, what Azure offers, and what open source offers.

The top row of tabs jumps to each big topic. The left panel lists every page, with the page you are on in black. The line under the tabs shows where you are, and the buttons at the bottom (or the ← and → keys) walk through every page in order.

Every number on these pages comes from the real claims assistant running on Azure, the same one the Series uses. Things that are designed but not built yet are labelled not built yet.

Ready? Start with the horse and the harness, or jump straight to one message, end to end. Prefer to learn by poking it? Open the Agent Harness Simulator: type a message and follow every step, check and JSON payload.
