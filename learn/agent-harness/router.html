Router

The router is the first thing that reads Rohan's words. It is not a model; it is a list of rules. Its job is to send each message down the cheapest path that is still safe, so the expensive, slow, unpredictable model is used only when it is really needed.

Goes inThe message text
What happensRules check for a hand-off, then a refusal, then a simple read with one reference
Comes outOne of four paths: Escalate, Refuse, Direct or Agentic

Why rules first? A rule is instant, free and gives the same answer every time, so it can be tested completely. If the rules aren't sure, the message goes to the loop, which can cope with anything. The rule is: when in doubt, use the loop; never guess on the cheap path.

Rohan saysPathWhy
"What's the status of claim CLM-019002?"DirectOne read-only question, one claim number
"What is the status of my claim?"AgenticNo claim number, so it needs to look up his claims first
"Please release the payment for claim CLM-010004."AgenticIt is a write; writes never take the Direct path
"Will my claim be approved?"Refuse (R-COVERAGE)The assistant may never promise cover
"My passenger was injured"Escalate (injury-reported)A person must handle injuries

class Direct(_Frozen):
    """Unambiguous — a deterministic handler answers without the model."""

    kind: Literal["direct"] = "direct"
    intent: IntentName
    handler: str
    args: dict[str, object] = Field(default_factory=dict)


class Agentic(_Frozen):
    """Ambiguous, multi-intent, or unmodelled. The loop is the fallback, not
    the default: when the classifier is unsure, it routes here."""

    kind: Literal["agentic"] = "agentic"
    goal: str
    candidate_intents: tuple[IntentName, ...] = ()


class Refuse(_Frozen):
    """Out of scope. The refusal list in the functional spec is normative —
    "never promise what the system cannot deliver" is only testable against an
    explicit list of things it must not say."""

    kind: Literal["refuse"] = "refuse"
    reason: str
    alternative: str | None = None
    rule_id: str = ""
    """Which rule refused, not just why in prose — the AOAS `refuses` id. Same
    argument as `Escalate.rule_id`: *"which rule refuses most often, and is it
    right to"* cannot be asked of a sentence."""


class Escalate(_Frozen):
    """A human takes over. Triggered by P-ESCALATE, or asked for outright."""
