Flow 18: The gateway refusing calls

Route: Gateway only. Groq's free tier allows 8,000 tokens a minute; one loop turn uses 1,500–2,500, so only 3–5 turns a minute.

What it teachesThe gateway enforces its own allow-list and Prompt Shields, whoever calls it. Backend headers leak through (F-125).
