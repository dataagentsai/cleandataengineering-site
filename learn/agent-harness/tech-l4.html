L4 · Control loop

Plan, act, check, with step and no-progress limits. Family: Think · one turn, in order.

Why our choiceAgents that touch money need every step testable and checks at exact positions. A hand-written loop has the lowest lock-in and works with any model.

DecisionWe write the loop ourselves and use Pydantic AI only as the model layer, so budgets and checks sit at exact, testable positions. We would use LangGraph for workflow-shaped agents, Agent Framework for a .NET team, and full Pydantic AI for simple A1–A3 agents.
