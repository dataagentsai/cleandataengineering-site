The APIM gateway

Between our harness and Groq sits Azure API Management (APIM), used as an AI gateway. It is one place where Azure can check every model call, whichever agent made it.

Content Safety runs two checks on the newest user message: Prompt Shields, a trained classifier for jailbreak attempts, and a harm check for hate, sexual content, violence and self-harm on a 0–6 scale (blocked at 4 or more). The answer gets the harm check too.

It fails open. If Content Safety itself is down, or the free 5,000-a-month quota is used up, the call is let through and the verdict is recorded as "unavailable". That is why our own checks still matter: see the pre-model check.

The Groq key never lives in our code; APIM fetches it from Key Vault with a managed identity.

Want every detail? The long version is in the Series: APIM, with the live policy file.

infra/policies/groq-api.xml:171. Only the allowed model gets through (403 model_not_allowed)
    <!-- Tier 4a A8: only an allowed model gets through. Checked first, so a refused
         request costs no Content Safety call and no tokens. The agent checks the
         same list (approved_models); this is the second wall, at the door. -->
    <set-variable name="model" value="@{
        var body = context.Request.Body.As<JObject>(preserveContent: true);
        return body == null ? "" : ((string)body["model"] ?? "");
    }" />
    <choose>
      <when condition="@(!"{{allowed-models}}".Split(',').Select(m => m.Trim()).Contains((string)context.Variables["model"]))">
        <return-response>
          <set-status code="403" reason="Model not allowed" />
          <set-header name="x-content-safety" exists-action="override"><value>skipped; prompt=skipped; completion=skipped</value></set-header>
          <set-header name="Content-Type" exists-action="override"><value>application/json</value></set-header>
          <set-body>@(new JObject(new JProperty("error", new JObject(new JProperty("code", "model_not_allowed"), new JProperty("message", "This agent may not use model '" + (string)context.Variables["model"] + "'.")))).ToString())</set-body>
        </return-response>
      </when>
    </choose>

        var body = context.Request.Body.As<JObject>(preserveContent: true);
        var messages = body["messages"] as JArray;
        if (messages == null) { return ""; }
        for (int i = messages.Count - 1; i >= 0; i--) {
            if ((string)messages[i]["role"] == "user") {
                var content = messages[i]["content"];
                var text = content.Type == JTokenType.String ? (string)content : content.ToString();
                return text.Length > 9000 ? text.Substring(text.Length - 9000) : text;
            }
        }
        return "";

infra/policies/groq-api.xml:714. The verdict: block on an attack or severity ≥ threshold; "unavailable" passes (fails open)
        <set-variable name="promptVerdict" value="@{
            var shield = context.Variables.GetValueOrDefault<IResponse>("shield");
            var harm = context.Variables.GetValueOrDefault<IResponse>("promptHarm");
            if (shield == null || harm == null || shield.StatusCode != 200 || harm.StatusCode != 200) { return "unavailable"; }
            var attack = shield.Body.As<JObject>(preserveContent: true)["userPromptAnalysis"]?["attackDetected"];
            if (attack != null && (bool)attack) { return "block:prompt-attack"; }
            foreach (var c in (JArray)harm.Body.As<JObject>(preserveContent: true)["categoriesAnalysis"]) {
                if ((int)c["severity"] >= {{content-safety-threshold}}) { return "block:" + (string)c["category"]; }
            }
            return "pass";
        }" />
        <choose>
          <when condition="@(((string)context.Variables["promptVerdict"]).StartsWith("block"))">
            <return-response>
              <set-status code="403" reason="Blocked by Content Safety" />
              <set-header name="x-content-safety" exists-action="override"><value>@((string)context.Variables["promptVerdict"] + "; prompt=" + (string)context.Variables["promptVerdict"] + "; completion=skipped")</value></set-header>
              <set-header name="Content-Type" exists-action="override"><value>application/json</value></set-header>
              <set-body>{"error":{"code":"content_safety","message":"the prompt was blocked by Content Safety"}}</set-body>
            </return-response>
          </when>
        </choose>
