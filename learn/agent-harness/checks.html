Checks at every point

A check is a small piece of code that looks at one thing (a message, an answer, a tool request, a result) and says pass or block. The harness has checks at eight points along a turn, because each kind of mistake can only be seen at one place.

Goes inWhatever is passing that point
What happensRun the checks placed there; the first block wins; a check that crashes also blocks
Comes outPass, or a named block with a safe next step

Almost every check is a plain rule. Rules are instant, free and give the same answer every time, so they can block safely in the middle of a turn. Azure adds three: a model allow-list, a rate limit, and Content Safety. No LLM judge runs inside a turn; judges are slow and costly, so they belong in offline eval.

What a block does depends on where it happens. Before or after the model, or before the reply, the turn ends with a safe reply: "I am not able to confirm that. Let me pass you to a colleague who can help." Before a tool, only that one call is refused, and the model is told why so it can choose again.

Fail closed. If a check itself crashes, that counts as a block. A broken guard must never mean an open door.

Who provides the checksOurs (harness and agent): about 30, all built, including every check that protects money. Azure APIM: 3. Pydantic AI: none (it only turns errors into types). Open source to add: Prompt Guard 2, and maybe Presidio for personal data.

Want every detail? The long version is in the Series: policy at every position, with the live file.

How it is done: the real code

def enforce(ctx: Context, rules: Sequence[Rule] | None = None) -> Verdict:
    """Run the rules for this position. First block wins.

    A rule that raises **blocks**. That is the whole of AAC-0091: a guardrail
    that errors open is believed and absent at once, and nobody goes looking for
    a control they think they have.
    """
    applicable = default_rules().get(ctx.position, ()) if rules is None else rules
    with tel.span("agent.policy", **{"agent.policy.position": ctx.position.value}) as span:
        for rule in applicable:
            name = getattr(rule, "__name__", repr(rule))
            try:
                verdict = rule(ctx)
            except Exception as exc:  # noqa: BLE001 — deliberate: fail closed
                span.set_attribute("agent.policy.blocked_by", name)
                span.set_attribute("agent.policy.errored", True)
                return block(name, f"rule failed and traffic was blocked: {exc}")
            if verdict.blocked:
                span.set_attribute("agent.policy.blocked_by", verdict.rule or name)
                return verdict
        return ALLOW
