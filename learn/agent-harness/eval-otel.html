What every span carries (OpenTelemetry)

Every span the agent emits is declared in a span contract: its name, the fields it must carry, and the ones it may carry. A test fails if code emits a span that isn't declared. These tables are read from the contract itself each time the site is built.

Goes inA step of the turn, such as one model call
What happensOpen a span with the contract's required fields; record errors; redact anything personal
Comes outOne row in App Insights (AppDependencies), with these fields as Properties

Every field, and what it means

FieldMeaning (from the code's own docstring)
agent.capturedThis turn's words were kept. Without the marker, a rule that found no contradiction in a turn whose reply was never recorded would count as a pass.
agent.config.fingerprint—
agent.context.charsHow full the assembled transcript was on this call. AAC-0103 says context growth is tracked across releases, and a committed baseline does that between releases. This does it *per call*, which is the half that tells you whether a threshold is anywhere near right — a system that never trims has headroom it is not using, and one that trims constantly is losing information silently.
agent.context.exchanges—
agent.context.stored_charsWhat the checkpoint actually holds, which is a different question from what the model was sent and was for a long time nobody's.
agent.context.trimmedUnits dropped to make the call fit. The number that decides whether the rest of the context work is justified or premature.
agent.cost.call_usd—
agent.cost.usd—
agent.enabledThe kill switch's state for this turn (`entrypoint.switch`, A13); absent where no switch is wired.
agent.escalation.idThe join key across raise, wait and lapse. Without one on every span, queue wait time is not computable from the trace.
agent.escalation.rule_idWhich rule fired. Sliced by this, the outcome of an escalation answers the question that tunes the rule set — AAC-0020's over-refusal rate, in the shape this agent actually has.
agent.escalation.tier—
agent.feedbackup · down, from the customer, against a conversation (AHC-0112).
agent.freshness.rowsHow many rows were read again because an irreversible action would otherwise have run on an old belief — AHC-0107. Worth a number rather than a flag: a rate that climbs says the world is moving faster than the conversation, which is a fact about the business and not about the agent.
agent.freshness.uncheckableSet when a belief was stale and the surface offered no way to read it again. Said out loud rather than passed over, because the alternative is a run that proceeded on an old value and left nothing to say so.

agent.model.malformedHow many provider responses could not be parsed this run — AHC-0001. An attribute rather than a log line: a parse failure rate is a number that moves when a model is swapped, and one that only exists in logs is one nobody plots.

agent.reply.redactedWhether redaction would change the reply — personal data or a secret in what the customer was about to be shown (AAC-0006). On every turn, not only captured ones, because it is the one content check that must not be sampled.
