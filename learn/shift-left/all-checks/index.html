FAQ

Questions people ask

How many checks does the shift-left bundle have?

137 today, in 13 families: cost in code, plans and config; security, secrets and dependencies; purity, tests and complexity; clean code and style; metric views; and repository setup.

How many of the checks come from existing open-source tools?

57 are an open-source tool's own rule, configured; 77 are written by us; the rest are on trial or use the platform's own command.
