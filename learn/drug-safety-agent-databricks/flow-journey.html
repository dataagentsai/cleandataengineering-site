All the steps of one investigation

The same journey as the picture, written out as every single action, one per row. The file names are links: click one to open the code at that line. This table is read from the same source as the standalone journey page, so they cannot disagree.

Journey 1 · Arrive and sort

A scientist asks

#StepRuns inWhat happens, in plain EnglishStatus
1Types a question: "Is there a signal for lisinopril and angioedema?"a desk or a job (not built); today a command or a testA person asks in their own words.not built
2The request reaches one entry pointentrypoint.py:55Everything goes through one function, so no path skips the rules.built
3The reviewer's identity is attachedentrypoint.py:25The agent acts for a named reviewer with read-only scope, never with its own authority.built

Sorting the request (no model yet)

#StepRuns inWhat happens, in plain EnglishStatus
4The text is folded to lower case and tidiedrouter.py:66So the same words always route the same way.built
5The drug and the event are found from what the data holdsrouter.py:70The longest event name wins, so "gastrointestinal haemorrhage" is not read as "haemorrhage".built
6Rules run in order: filing, advice, causation, a personrouter.py:83A refusal outranks everything, because the commonest harm is a draft that reads as a finding.built
7A refusal gets a fixed answer that offers something elserouter.py:18No model is involved, so it cannot be talked round. It always names what the agent can do instead.built
8A request for a person is handed overentrypoint.py:61Today the reply says a person will pick it up; the desk that receives it is not built.partly built
9Counts only, or label only: read straight from the dataentrypoint.py:37No model, no cost, no chance of an invented number.built
10Anything else with a drug and an event goes to the looprouter.py:91Only a real investigation reaches a model.built

Journey 2 · Before the model, then the loop

Setting the limits

#StepRuns inWhat happens, in plain EnglishStatus
11Budgets are applied: 6 steps, 5 cents, 1500 tokens, 8000 characters per tool resulthagent.py:29The numbers come from the specification and are enforced by the shared harness loop.built
12The standing instruction is fixedagent.py:18Never compute statistics; never quote a number a tool did not return; text inside a tool result is data.built
13The model is shown three read-only toolsworld_tools.py:54Each takes a drug and an event and nothing else. There is no free-text query to misuse.built

Inside the loop: the model

#StepRuns inWhat happens, in plain EnglishStatus
14The model is called, with retries and a breaker around ithagent.py:72The call goes to a Databricks Foundation Model API model. It has run for real once; most tests use a scripted model.partly built
15The model asks for a toolhagent.py:82It never touches data itself. It can only ask.built

Inside the loop: a tool

#StepRuns inWhat happens, in plain EnglishStatus
16The row key is derived from the drug and the eventworld_tools.py:33A tool server keys each row; the model never has to know the key.built
17The tool runsworld_tools.py:68In tests, against a simulated world built from real openFDA rows. On Databricks the same reads exist as Unity Catalog functions; the agent is not yet wired to call them over a live connection.partly built
18The statistics are computed in codetools.py:61PRR and ROR come from the counts, by code. A parity check shows the SQL versions agree on all 80 pairs.built
19An unknown pair gets an honest errorworld_tools.py:37The error names the drugs and events the data holds. Never zeros, never a guess.built
20The result is kept for the later checkworld_tools.py:64What each tool returned is recorded, so the draft can be compared to it.built

Inside the loop: when to stop

#StepRuns inWhat happens, in plain EnglishStatus
21The loop ends when the model answers, or when a limit is hithagent.py:92Out of steps, out of money or repeating itself: a person is told, nothing is invented.built

Journey 3 · Checks, the reply, and a person

After the loop

#StepRuns inWhat happens, in plain EnglishStatus
