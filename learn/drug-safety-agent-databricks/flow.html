Drug-Safety Agent on Databricks · End to end

Follow one question end to end

A question takes one of four paths, and the first thing that happens is a set of plain rules, not a model. Only a real investigation reaches the loop. Everything that must be refused or handed to a person is decided before any model is paid for.

Goes inA sentence from a scientist, plus who they are
What happensThe router picks one of four paths. Only the investigate path calls a model, then checks run on its draft
Comes outA reply: a refusal, a hand-off, a direct answer, or a checked draft

Why the router goes first. The most harmful mistake this agent could make is a draft that reads like a finding. Putting the refusals in front of the model means no clever wording can talk the agent into one. It also saves money: a plain count never needs a model.

One front door. Every request enters through a single function, handle, so no path can skip the rules. Read the router next, or jump to all steps in one table or one real run.

The real code

Cut from the repository each time this site is built, so it always matches what runs. Each header names the file and the line it was cut from.

src/drugsafety/entrypoint.py:55handle(): the whole agent as a caller sees it
async def handle(text: str, *, reviewer_id: str, llm, tools) -> Reply:
    who = identity_for(reviewer_id)
    r = route(text)
    if r.answered_by == "refusal":
        return Reply(REFUSALS[r.refusal or ""], r)
    if r.answered_by == "handoff":
        return Reply(HANDOFF, r)  # the escalation desk (L14) is not built: the reply is the whole of it, for now
    if r.answered_by == "direct":
        return Reply(await _direct(r, tools, who), r)
    if r.intent == "investigate":
        d = await hagent.investigate(llm, r.drug or "", r.event or "", tools=tools)
        if d.status != "draft" or d.body is None:
            return Reply(f"I could not finish this investigation, so I am passing it to a person. ({d.reason})", r, d)
        if (problems := hagent.grounding(d)):
            return Reply("A number in my draft did not match what the tools returned, so I am passing it to a person. "
                         + "; ".join(problems), r, d)
        return Reply(_say_draft(d.body), r, d)
    return Reply("I investigate whether a drug and an adverse event form a signal in public reports. Name a drug and an event, "
                 "or ask for the report counts or whether the label mentions it.", r)
