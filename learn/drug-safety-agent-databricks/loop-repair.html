When the draft is malformed: one repair turn

Models sometimes reply with almost-right JSON: a missing field, a number written as text. Rather than fail at once or accept it, the agent tells the model exactly what was wrong and asks again, one time. A second failure becomes a hand-off to a person, with the reason.

Goes inA reply that broke the output contract
What happensSend the list of problems back as a message; ask for only the corrected JSON
Comes outA valid draft, or a hand-off naming what broke

One, not many. Repeated repairs hide a model that cannot do the job and burn the budget. One repair turn recovers the common slip; after that a person should look.

        if not isinstance(again, Completed):
            return done("needs_human", None, "the repair turn ended without an answer", again)
        body, problems = _parse(again.reply)
        if problems:

        result = again
    return done("draft", body, "", result)
