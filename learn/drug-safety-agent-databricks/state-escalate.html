Hand-off to a person

Several paths end with "a person will pick this up": the scientist asked for one, the loop ran out of steps, a tool was down, or a draft failed a check. The reply says so, but nothing receives the case yet.

ReasonTodayNeeded
The scientist asks for a personFixed replyA queue entry with the request attached
The loop stopped without an answerReply with the reasonA queue entry with the trace
A draft failed the grounding checkReply listing the mismatchesA queue entry with the draft and the mismatches
A tool was unavailableReply with the reasonA queue entry; retry later

Say it once. The specification asks that a person is told once and not repeatedly. That needs state too, so it waits on the same piece of work.
