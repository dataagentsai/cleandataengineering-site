The store and the decision rules

The store holds each assessment with a status. The agent can only put a draft in. A person can then approve, edit or reject it. After that it is final. These rules live in the store, not in a prompt, so no wording of a question can bend them.

RuleWhat the code doesProved by
The agent only draftsIt is offered one write tool, draft_assessment, and none to decide. The numbers in a draft are re-read from the data, whatever the model passes.test_the_agent_is_offered_no_way_to_decide; test_the_numbers_stored_come_from_the_data
One assessment per pairThe same drug and event always give the same id. A waiting draft is updated; a decided pair is never redrafted.test_a_decided_pair_is_not_redrafted
A decision needs a nameAn empty reviewer is refused and nothing changes.test_a_decision (8 rows)
A decision is finalApproving, rejecting or editing an already-decided assessment is refused.test_a_decision_is_final (4 rows)
An edit must still be validBlank or mistyped fields are refused, so an edit cannot break the draft's shape.test_a_decision, the edit rows
Every write is on a trailWho drafted, who decided, who claimed a hand-off, and when.test_every_write_is_on_the_audit_trail

The scenario that used to fail. One of the ten scenarios, a draft assessment lands when every condition holds, failed because there was nowhere for it to land. It now passes, and all ten pass.

Next. Move the table to Delta, put a login in front of the desk, and tell a reviewer when something is waiting. The agent's code does not change for any of those: they sit behind the same store.

    def decide(
        self, aid: str, reviewer_id: str, decision: str, *, edited_body: dict[str, Any] | None = None, note: str = ""
    ) -> Assessment:
        if decision not in DECISIONS:
            raise StoreError(f"decision must be one of {sorted(DECISIONS)}")
        if not reviewer_id.strip():
            raise StoreError("a decision must name the reviewer")  # P-APPROVER
        row = self.db.execute("SELECT status FROM assessments WHERE id=?", (aid,)).fetchone()
        if row is None:
            raise StoreError(f"no assessment {aid}")
        if row["status"] != "drafted":
            raise StoreError(f"{aid} is already {row['status']}; a decision is final")  # P-APPROVAL-FINAL
        if decision == "edit":
            problems = validate_body(edited_body)
            if problems:
                raise StoreError("the edited draft is not valid: " + "; ".join(problems))
        self.db.execute(
            "UPDATE assessments SET status=?, decided_by=?, decided_at=?, edited_body=?, note=? WHERE id=?",
            (DECISIONS[decision], reviewer_id, _now(), json.dumps(edited_body) if decision == "edit" else None, note, aid),
        )
        self._audit(reviewer_id, DECISIONS[decision], aid, note)
        self.db.commit()
        return self.get(aid)
