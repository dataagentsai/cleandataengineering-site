Foundation Model APIs

Foundation Model APIs host open models so you do not run them. They speak the same request format as the OpenAI API, so the agent's model port connects to them with a base URL and a model name.

Which model. A strong open model such as gpt-oss-120b suits this job, which is tool calling with short structured answers. For choices across vendors see the site's which model page.

What is true today. An adapter for the Databricks endpoint is written. The 20-pair evaluation ran on the same open model through another host. Running the identical evaluation on the Databricks endpoint is the step that would make the "built on Databricks AI" claim fully evidenced.
