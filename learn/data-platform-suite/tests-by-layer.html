What each layer has: tests, golden data, incidents, and what is missing

This page answers one question exactly: for each layer of the platform, what proves it? It lists the test files, says whether the layer is compared with the oracle's golden data, names the planted incidents it is judged on, and says what is missing.

How to read the counts

The number after each file name is the number of test functions in the file. It was counted when this page was built, by searching each file for lines that start a test function. It is a count of functions, not of cases. A table-driven function with twenty rows counts as one, so the number of cases that actually run is larger.

The obligation coverage check

The specification catalog holds a list of obligations: rules the platform must keep, each with an id such as DEL-01. The coverage check asks a plain question of each one. Does any test file cite its id?

StateMeaning
testedA test file contains the id.
waivedA waiver names the id, with a reason of at least 10 characters, an approver and an end date that has not passed.
builtOnly code contains the id. The rule is kept somewhere but no test says so.
noneNothing cites it.
src/dataplatform/governance/coverage.py:53The whole check: a test beats a waiver, a waiver beats code.
def coverage(rules: list[Rule], tests: Mapping[str, str], code: Mapping[str, str],
             waivers: list[Mapping[str, Any]], today: date) -> list[Covered]:
    waived = {str(w["id"]): str(w["reason"]) for w in waivers if valid_waiver(w, today)}
    out = []
    for r in rules:
        t = _cited(r.id, tests)
        if t:
            out.append(Covered(r, "tested", t))
        elif r.id in waived:
            out.append(Covered(r, "waived", (waived[r.id],)))
        else:
            c = _cited(r.id, code)
            out.append(Covered(r, "built" if c else "none", c))
    return out
src/dataplatform/governance/coverage.py:42What cited means: the id as a whole word in the file's text.
def _cited(rule_id: str, files: Mapping[str, str]) -> tuple[str, ...]:
    pat = re.compile(rf"(?<![A-Z0-9-]){re.escape(rule_id)}(?![0-9])")
    return tuple(sorted(name for name, text in files.items() if pat.search(text)))

What this check does and does not say

Cited is a weak word. A test that mentions an id in a comment counts as much as a test that proves the rule. The check finds obligations nobody has written a test for. It does not measure how well the tested ones are tested, and it does not run the tests.

Not built yet, or known gaps
  • The success criterion for coverage says 89 of 89 rules. The catalog now holds 105, and 59 are cited by a test.
  • The six waivers are proposed and unsigned, so the count of waived obligations is zero.
  • Coverage counts a citation, not a passing test. A cited test that is skipped still counts.
  • No golden-data test exists for the metadata store or for operations. Both are proven by contract tables and, for operations, by a stand-in run log.
  • Gold has no test file of its own that runs the 14 days and asserts equality with the oracle each day, the way silver and bronze have.
  • The script reads workflow files as tests too. The public snapshot has no workflow folder, so any obligation that only a workflow proves shows as untested here.
