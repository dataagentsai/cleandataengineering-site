Who calls what: every function and method

When you find a function and wonder who starts it, look it up here. Each page below covers one group of modules and lists every class, function and method in it, with the places that use it and the tests that name it.

1,847 definitions and 4,371 uses were found by reading 183 modules. The callers are not run-time facts: a function passed through a variable, a callback registered at run time, or a call made through a dictionary of names may be missing. A function the day loop starts through runpy or a job file shows as started from outside the code.
