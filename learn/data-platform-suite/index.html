The one picture

Five words carry the whole design. Landing is where files arrive, untouched. Bronze keeps every batch exactly as received, so nothing is ever lost. Silver is the cleaned, trusted copy, one row per business key or per version. Gold is shaped for questions: dimensions and facts. The semantic layer gives each metric one definition.

Under all of it sits the metadata store, a small database. It holds the settings for every dataset and a record of everything every run did. The code is the same for every dataset. Only the settings differ. That is what metadata-driven means.

The example used everywhere

The pages use one made-up company: a tyre maker with a sales system, a factory system, a laboratory, dealers, and presses that send readings. It has nine datasets, chosen so that between them they need every way of loading and every kind of history.

You can also ask the platform to explain things without opening a browser. python scripts/explain.py run, metadata, cicd and code print plain-language text from a run's files, a dataset's manifest, the repository's checks, and the code itself. They use no model and no network, so the same inputs always give the same text.

What is real and what is not

The code is real and runs. The tyre company is simulated: a program plays the company day by day, sends its data through the platform, and knows the true answer for every day. That is how each layer is checked. The source connectors used in these runs are local stand-ins, not connections to real business systems. Each layer page says what is not built yet.
