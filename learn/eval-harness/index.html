Checking what an AI agent did

An AI agent can write a perfect, polite reply and still be wrong: it can say “your refund has been issued” when no refund was issued, or pay a claim nobody looked up. Reading every conversation by hand doesn't scale. This framework reads what the agent did and checks it against the rules you wrote down.

How to use this tutorial

Read the tabs left to right. Each section teaches first and then shows the code. Pages that need your opinion end in a yellow “Your review” box. The Your review tab collects every question in one place.
