Checks by kind of agent

These depend on how the system is built, not on the business. A retrieval-based answerer must cite real sources; a tool-using agent must stop when it's going round in circles. An obligation can belong to several kinds, so it may appear more than once. FNOL and the clothing agent are both A4 (conversational) and A6 (tool-using).

A1 · Single-Turn Transform

One call in, one answer out. No tools, no retrieval, no memory. The model transforms text it was given.

AAC-0017MUSTPer-slice accuracy, not just aggregate—
AAC-0018SHOULDStability under paraphrase and reordering—
AAC-0019MUSTContext-window overflow behaviour—
AAC-0020SHOULDOver-refusal rate on in-scope inputs—
AAC-0021SHOULDPosition and length bias in the output—

A2 · Structured Extractor

Output is a typed object consumed by downstream code rather than read by a human. Separate from A1 because a schema turns quality failures into type failures.

AAC-0023MUSTType, unit and format fidelity—
AAC-0024MUSTAbsent fields are null, never invented—
AAC-0025MUSTField-level precision and recall against gold—
AAC-0026SHOULDSchema evolution does not break consumers—
AAC-0027MUSTThe downstream consumer is tested on real output—
