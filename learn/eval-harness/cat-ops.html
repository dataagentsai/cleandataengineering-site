Ops questions answered from traces

Agent and LLM traces go to LangSmith, Langfuse, App Insights, or as numbers to Prometheus. Whichever tool it is, an ops person asks the same questions of them. This page lists those questions. It is the specification for the saved questions and the ready-made dashboard packs: each one gets built once as a definition and compiled into each tool's own form, as the saved questions already are.

What a question can need

NeedMeaning
metaSpan metadata: times, status, model, token counts, tool name
contentPrompt and response text (content capture on)
verdictEval or guardrail results written as events
priceA price table to turn tokens into money
outcomeA resolved / not resolved signal per task
versionA release, prompt or model version tag on spans
feedbackUser ratings sent as events
Who can answer

The trace stores (LangSmith, Langfuse, App Insights) can answer every question. Prometheus holds numbers only, so it answers a question when the answer is a count, rate or trend about all traffic, and never when you need to open one conversation or read its text. This is worked out by one rule in the code, not by hand.
