Hooks in a loop of your own

Your question: a framework gives us hooks before and after model and tool calls. In our own loop, code added “before a tool call” runs for every tool. How do we run something before one tool only, and keep injection points simple?

The answer is two separate jobs.

  1. The loop only reports the moment. Five lines, one per moment, each saying “here's what's happening”: which tool, its arguments, the conversation so far. These lines never change, however many rules you add.
  2. Each hook says what it's for. Targeting lives on the hook, as a matcher: one tool by name, a family by pattern (issue_*), or a whole kind of tool (every irreversible one). The loop never has an if tool == ….

The five lines in your loop

Your own loop, with the five moments marked
for step in range(max_steps):
    hooks.run(Event("pre_model", text=prompt))              # 1
    reply = model(messages)
    hooks.run(Event("post_model", text=reply.text))         # 2
    for call in reply.tool_calls:
        d = hooks.run(Event("pre_tool", tool=call.name,     # 3
                            arguments=call.arguments,
                            side_effect=registry[call.name].side_effect,
                            session=session))
        if d.stops:                      # block or escalate: the tool never runs;
            result = refused(d)          # the model is told why
        else:
            result = tools[call.name](**(d.arguments or call.arguments))
            hooks.run(Event("post_tool", tool=call.name, result=result))   # 4
    ...
hooks.run(Event("reply", text=final_text))                  # 5

Targeting one tool, three ways

In code: decorators, like a framework's hooks
hooks = Hooks()

@hooks.before_tool("issue_refund")                 # one tool
def refund_cap(event):
    if event.arguments["amount"] > 10_000:
        return Decision("escalate", "refunds over ₹10,000 need a person")

@hooks.before_tool("issue_*")                      # a family of tools
def ...

@hooks.before_tool(side_effect="irreversible")     # every tool of a kind
def ...

hooks.add("pre_tool", check(refund_needs_lookup), tools=["issue_refund"])   # any of our checks
In YAML: no code at all (what an ops person writes)
evaluators:
  refund_needs_lookup:
    adapter: requires_before
    action: issue_refund
    before: get_order
    at: pre_tool               # the moment
    tools: [issue_refund]      # the matcher: which tools
    on_fail: block             # block · escalate · allow (just record)

Why this stays simple and effective

Simple: one entry point, five calls, one decision type; rules are added in YAML or with a decorator, never in the loop. Effective: unmatched hooks cost nothing; the first block stops the rest; matching by kind of tool covers tools nobody listed; and the same hook runs in your loop, in a framework (an adapter turns its hook into an Event), or at the gateway. Still to come in Tier 3: a time budget per moment, fail-closed when a hook breaks, and every decision recorded on the trace.

The hook runner, in real codesrc/evalharness/hooks.py:157
    def run(self, event: Event) -> Decision:
        """Every hook for this moment whose matcher fits, in order. The first
        block or escalate wins; a modification is handed on to the next hook."""
        changed: Decision | None = None
        for placed in self.placed:
            if placed.position != event.position or not placed.match.matches(event):
                continue
            decision = placed.hook(event) or ALLOW
            decision = replace(decision, hook=decision.hook or placed.name)
            if decision.stops:
                return decision
            if decision.action == "modify":
                changed = decision
                event = replace(
                    event,
                    arguments=decision.arguments
                    if decision.arguments is not None
                    else event.arguments,
                    text=decision.text if decision.text is not None else event.text,
                )
        return changed or ALLOW
