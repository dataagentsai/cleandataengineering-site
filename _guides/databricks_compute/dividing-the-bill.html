Dividing the bill

Best architecture for dividing the bill

Chargeback works when three things are true: every unit of compute is owned by exactly one BU and environment, that ownership is written down as a tag by a rule (not by hand), and one rollup table turns tags into money.

Rules that make any layout work: a single naming standard for tags (bu, env, cost_center, project, owner); production jobs run as service principals named per BU, never as people; one SQL warehouse per BU, environment and workload class so usage is not mixed; set budget policies and alerts, not just reports; and review the untagged line every week.

The per-user and per-query gap. Billing is recorded per warehouse or cluster, not per query or per person. If five teams share a warehouse, you can only split its cost by estimating, using each team's share of query time from query history. That estimate is fair but is not an invoice figure. This is the strongest argument for separate warehouses per BU.
