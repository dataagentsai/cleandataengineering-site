About

What this site is

A free, open place for engineers who work with data and AI, to learn how real systems work and to build them together. It's a community, not a course you buy: no sign-up, no paywall, no ads, and it stays that way.

How it is organised

Everything follows one loop. You see a system drawn, you run it in a simulator, you build it with others, and you prove it against an open standard. What you build becomes the next thing someone else learns from.

1 · See itCourses, paths, concepts 2 · Run itSimulators you can break 3 · Build itCommunity projects 4 · Prove itOpen standards

Not sure where to start? Pick your role and cloud for a path from beginner to advanced. Worried about what AI means for your job? Read the lion story first. Studying for an exam? Certification prep.

What we hold to

  • Free, always. Everything here, for everyone.
  • Pictures before detail. Every system is drawn first; every box opens the next level down, to the real code.
  • Honest numbers. A number is either recorded from a real run or labelled illustrative. Every product page says what is built and what is not.
  • Ideas before products. The specs name no product; a separate binding says which product does each job on each cloud.
  • Learn in public. We write up what broke and what the fix turned out to be.

Who runs this

Started by Basant Choudhary: twenty-three years inside enterprise data platforms, now building and reviewing AI systems that have to survive real data and real operations.

Join in

Pick a project with open work, or lead one that needs a lead. Write a lesson or a post: we help you shape it and share it in Writing. Code and specs are on GitHub.
