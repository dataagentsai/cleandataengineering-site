CCA-F mind maps: every decision table in one place

Every question in mock exams 4 to 7 ends with a mind map: a small table that says what you see, what is really wrong, and which fix fits. Many questions shared the same kind of decision, so their tables have been merged. That turns 240 tables into 83 mind maps, each named by the decision it helps you make.

1. Find the decisionRead the "Mind map for" column below and pick the one that matches the question in front of you.
2. Match the symptomIn the table, find the row that describes what the question tells you. The fix in that row is usually the answer.
3. Check the neighbour rowThe row next to it is often the runner-up option. Find the sentence in the question that rules it out.
