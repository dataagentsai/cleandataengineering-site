Docs have moved past the exam guide. The guide is from March 2026, but the Databricks docs changed several names in the months after it. The exam tests the guide's names, so this site uses them and notes the new names on the cards.
  • Mosaic AI Vector Search is now called Databricks AI Search. Many APIs still use "vector-search" in paths and identifiers (docs).
  • Knowledge Assistant and Supervisor Agent (the guide's "Multiagent Supervisor") are labelled legacy for new agents. The docs point to Genie Agents (formerly Genie Spaces), the Agent Bricks CLI and Agent Runtime on Databricks Apps (docs). The guide still tests all three Agent Bricks.
  • The serving-endpoint AI Gateway is labelled legacy beside the newer Unity Gateway, which has the same jobs: rate limits, inference tables, usage tracking, and guardrails through service policies (docs).
  • Databricks Asset Bundles appear in the docs as Declarative Automation Bundles.

Services and features map

Only what the March 2026 outline covers. "Depth" is this site's reading of the objectives: High means expect several questions on details and trade-offs; Light means know what it's for.

Databricks pieceWhat it's forExam depthSections
Agent Bricks: Knowledge AssistantNo-code document Q&A agent with citations over UC volumes, tables or indexes; SMEs improve it with labelled questions and guidelines.Medium: when to use it vs build your ownS1
Agent Bricks: Supervisor Agent (Multi-Agent Supervisor)Coordinates subagents and tools, including Genie, agent endpoints and UC functions. Each end user needs access to each subagent.MediumS1
Agent Bricks: Information ExtractionTurns documents into JSON for a schema you define. Built on ai_extract; runs from SQL, a pipeline or a REST endpoint.MediumS1
Mosaic AI Vector Search (now AI Search)Managed vector index. Endpoint types: standard (about 320M vectors at 768 dims, high QPS) or storage-optimized (over 1B vectors, about 250 ms slower, triggered sync only). Index types: Delta Sync (managed or self-managed embeddings) or Direct Vector Access. Supports hybrid search, filters and a reranker.High: create, query, choose an endpoint, keep in syncS2, S4
Delta Lake + Unity CatalogChunk tables (Change Data Feed on for Delta Sync), volumes for raw files, three-level names, grants, models and functions in UC, row filters and column masks.HighS2, S4, S5
AI Functionsai_query (general batch inference in SQL), ai_parse_document (PDF, Office and images to elements), ai_extract, ai_mask, ai_classify, ai_summarize.Medium: batch inference with ai_query is an objectiveS2, S4, S5
Foundation Model APIsDatabricks-hosted LLMs and embedding models. Pay-per-token (including a priority tier) for prototyping, provisioned throughput for production, fine-tuned weights and HIPAA.HighS3, S4
Model ServingEndpoints for agents, custom models and external models. Permissions are CAN VIEW, CAN QUERY and CAN MANAGE. Resource access works through automatic passthrough (declared resources), on-behalf-of-user (preview) or secrets.HighS4
MLflow models: pyfunc and models from codeWrap a chain with pre- and post-processing, set a signature and input example, log dependencies, and register to UC with aliases (no stages).HighS4
Mosaic AI Agent FrameworkAuthor agents with MLflow ResponsesAgent, tools from UC functions, retriever tools, and deploy with agents.deploy(). Deploying also sets up a Review App, tracing and inference tables.HighS3, S4
LangChain on Databricksdatabricks-langchain classes: ChatDatabricks, DatabricksEmbeddings, DatabricksVectorSearch retriever, UCFunctionToolkit, GenieAgent.MediumS3
Genie Spaces (now Genie Agents) and Conversation APINatural-language questions over tables. The API returns SQL and results and applies the caller's UC permissions. In multi-agent systems, Genie is the structured-data worker.MediumS3
MLflow Prompt Registry (Beta)Immutable prompt versions, movable aliases such as @production, loaded by URI. This is how you promote prompts across environments and roll back.MediumS4
MCP serversManaged (Databricks-hosted: Genie, Vector Search, UC functions, SQL), external (third-party, registered through a UC connection with secrets) and custom (your own, hosted on Databricks Apps).MediumS4
Agent memory (Lakebase)Sessions keep one conversation; memory keeps facts across conversations. Both are managed and backed by Lakebase.Light to mediumS4
Databricks Apps, Review App, Slack/TeamsUser-facing interfaces. Apps keep tokens server-side and use the signed-in user's identity. The Review App collects SME feedback. Genie integrates with Teams and Slack.MediumS4, S6
MLflow evaluation: judges and scorersmlflow.genai.evaluate() with built-in judges. Correctness, RetrievalSufficiency and ToolCallCorrectness need ground truth; RelevanceToQuery, RetrievalRelevance, RetrievalGroundedness, Safety and Guidelines don't. Custom @scorer functions; make_judge and judge alignment from SME labels.HighS6
MLflow TracingRecords every step's inputs, outputs, latency and tokens. Autolog covers common frameworks, and @mlflow.trace covers your own functions.MediumS6
Production monitoring (Agent Monitoring)The same scorers run on a sample of live traces (register() then start(sampling_config=...)). Beta.MediumS6
AI Gateway (legacy; now Unity Gateway)On serving endpoints: inference tables (requests and responses to Delta), usage tracking (system.serving.endpoint_usage), rate limits (QPM/TPM by endpoint, user or group), guardrails (safety filter; PII Block or Mask; preview).HighS3, S5, S6
Cost controlsPay-per-token vs provisioned throughput, scale to zero, rate limits, smaller models, batch with ai_query, usage system tables. Serverless budget policies only tag usage; they don't cap spend.MediumS6
Open-source parserspypdf / PyPDF2 (PDF text), unstructured (mixed formats), Tesseract / pytesseract (OCR on scans), BeautifulSoup (HTML).Light: pick the right package for the formatS2

Two-week study plan

About 90 minutes a day, starting the day after AI-103. S3 and S4 together are 52% of the exam, so they get four days. Where Azure or Claude already taught the concept, read the bridge line on the card and spend the time on the Databricks names.

DayStudyPractice
Day 1Re-read the official exam guide (it asks for this two weeks before the exam). Read this hub's map and drift note, then the S1 cards.S1 practice bank

Day 3S3 clusters A and B: frameworks, choosing models, prompts, guardrails. Skim anything you already know from AI-103 and CCA-F.First half of S3 bank
Day 4S3 cluster C: Agent Framework, evaluation vs monitoring, Genie in multi-agent systems.Rest of S3 bank

About the questions: every practice item is original, written to the exam guide's objectives. None is a real exam question, and none comes from a dump.
