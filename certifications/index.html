Certifications

Free prep for AI certifications: a study guide, practice by domain, and mock exams written to feel like the real thing, where the questions are easy to read and the choice between answers is hard.

Anthropic

Claude Certified Architect – Foundations (CCA-F)

Designing with Claude: agentic architecture, Claude Code, prompt engineering, tool design with MCP, and context management.

Trap gym

The exam's questions are easy to read; the hard part is that every option is a sensible practice. Each trap gym page takes one trap, plays the options out in a simulator, and ends with exam-style practice. First up: Prompt or hook?

Mock exams

Take #7 in plain style first: it reads like the real exam, and all four options work, with one fitting best. Then the original #7 and #6 as a stretch. You can't pass any of them by picking the longest option.
